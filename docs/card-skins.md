# Card appearance

The home account toolbar opens **Skin bài ♠**. Six new free themes (Neon Circuit, Ruby Royale, Golden Flame, Arctic Glass, Violet Galaxy, Jade Dynasty) and Bella Classic share a front/back preview and an explicit Apply button. Choosing a preview does not change the table until Apply.

Selection is cosmetic and device-local (`bella.card-skin` in localStorage), not an account purchase or a multiplayer room setting. All rendered cards inherit the selected palette, including community, hole, and revealed opponent cards. Empty board slots and existing winning/losing treatments are excluded from theme face styles. Hearts/diamonds retain a distinct warm color, while spades/clubs use the theme's cool/light ink. The artwork uses CSS gradients and patterns, without image downloads or API calls.
