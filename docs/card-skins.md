# Card appearance

The home account toolbar opens **Skin bài ♠**. Six themes (Neon Circuit, Ruby Royale, Golden Flame, Arctic Glass, Violet Galaxy, Jade Dynasty) each cost 3 coins. Bella Classic is free. All share a front/back preview and an explicit Apply button. Choosing a preview does not change the table until Apply. Locked themes require purchase confirmation; insufficient balances cannot purchase.

Ownership and equipment are stored server-side per account (`ownedCardSkins`, `equippedCardSkin`). Existing accounts default to Classic; the earlier local free-preview selection grants no paid ownership. Purchase price comes from the shared catalog, with atomic balance updates and duplicate-purchase protection. Equip rejects unowned themes. Selection is cosmetic, not a multiplayer room setting. All rendered cards inherit the selected palette, including community, hole, and revealed opponent cards. Empty board slots and existing winning/losing treatments are excluded from theme face styles. Hearts/diamonds retain a distinct warm color, while spades/clubs use the theme's cool/light ink. The artwork uses CSS gradients and patterns, without image downloads or API polling.
