# Random skin pack

Pack cost: 10 coins. Server-side crypto randomInt(105) uses tier weights 50:35:15:5 for prices 3/10/15/20; displayed normalized probabilities are 47.62%, 33.33%, 14.29%, 4.76%. Selection is uniform within the chosen tier and includes already-owned skins. Duplicates do not add another copy or refund coins; the confirmation explains this before purchase. Free farmer is excluded.

The account CAS persists the resulting skin and tier in a request-ID receipt together with the debit and ownership update. Repeated requests use the original result without charging again. Retry after a network failure preserves that request ID. Existing ownership is retained after repricing. Sydney is now in the 20-coin tier alongside Iron Man and Sơn Tùng MTP.
